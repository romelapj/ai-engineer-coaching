# Bitácora del curso

Por qué el curso es como es. Esta carpeta no documenta el contenido (eso está en
los decks y los talleres) sino **las decisiones**: qué se probó, qué falló, qué
se cambió y con qué evidencia.

Existe porque el curso ya pasó por dos rediseños de formato y en ambos se perdió
el rastro del razonamiento. La tercera vez queda escrita.

## La regla que resume todo

> El código que ve el alumno **es** el código que corre. Nunca una copia.

Si una decisión futura rompe esa regla, se documenta aquí antes de tomarla.
